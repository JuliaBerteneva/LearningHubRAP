# Personal Growth Apps — RAP Practice Project

This repository contains a set of **RAP-based Fiori applications** designed for professional growth tracking.

## 🧠 Overview

The system currently includes three apps:

1. **Learning Hub** — course catalog (admin & user functions)
2. **My Courses** — personal learning management
3. **Analytics** — overview of progress and activity

All apps are:

- Built using **Managed RAP BOs**
- Integrated with **Fiori Elements** (List Report, Object Page, Analytical Page)
- Include **actions, validations, feature control, and authorization management**

## 🛠️ Tech Stack

- ABAP RAP model (Managed)
- CDS Views & Behavior Definitions
- Fiori Elements (generated via VS Code)
- Fiori Launchpad configuration

## 📈 Purpose

This project is part of the *Personal Growth Apps* series — a set of small, real-life logical apps for tracking learning and growth activities of employee
